# Verdict — F01 "Identity does not transfer by injection"

Reviewer: zero-context skeptic (never seen ECHELON). Read: README.md, _gate/SKEPTIC-BRIEF.md, F01.
**VERDICT: FAIL — step 3 (mechanism not reproducible).** Steps 1, 2, 4, 5 pass; step 5 raises flags that do not fail the pass but must be fixed.

## Step 1 — claim restated (PASS)
Loading an agent's identity documents into its context makes it able to *recite* those values without making it *act* from them, so a boot must be judged by behaviour rather than recall; and the conversational material that formed the identity cannot be compressed into a ~10k-token handover.

## Step 2 — evidence line (PASS, weakly)
The finding does not rest only on assertion. It offers:
- a counted duration: *"booted with all 13 CVs in context and ran hollow for 11 messages"*;
- a measured repair: *"roughly 29,000 tokens"* for a full cold re-anchoring;
- an arithmetic ceiling that shows its work (3k+2k+2k+2k+1k = 10k skeleton);
- a disconfirming observation kept in place (the 2026-04 Copilot bootstrap injection that *did* change output), with the finding's own limits stated: "one incident each, no controls, no repeat runs."
This clears "evidence is assertion." It is witnessed use plus numbers. It is n=1 and the finding says so, which is why the pass is weak rather than clean. The single load-bearing observable — "hollow" — is a texture judgement by an interested party, and the finding concedes this in the "could be wrong" section.

## Step 3 — five-line rebuild (FAIL)
Attempted rebuild from the text alone:

```
1. peeks   = recall_warm(intent)            # pointers + spine snippets; no bodies; no write
2. chosen  = agent_selects(peeks)           # ??? selection rule not given
3. bodies  = remember(chosen)               # only body door; "earns weight" = ??? undefined effect
4. boot    = pose_questions(bodies)         # ??? what questions, from what template
5. verdict = judge_behaviour(session)       # ??? judged against what baseline, by whom, on what rubric
```

Three gaps stop this from being reproducible by a stranger:
- **`earns weight` has no referent.** The finding says the fetch "earns weight" and that this is "the signal," but never says what weight is, where it is stored, or what consumes it. Without that, `remember` is indistinguishable from `cat` plus a log line — and the finding's own punchline is `remember`, not `cat`. The claimed difference is exactly the undefined part.
- **`judge_behaviour` has no procedure.** The claim is explicitly falsifiable — "judge behaviour rather than recall," compare against "a blank session" — but no rubric, no task set, and no blank-session control appear anywhere. The falsification test named in the Claim was never specified well enough to run, and (by the finding's own admission) never run.
- **`pose_questions` has no content.** "Seeds and questions, never 'you are X'" is a prohibition, not a construction. I cannot build a boot from it.

Per the brief this is FAIL: "mechanism not reproducible", gap named above.

This sentence carries the entire mechanism and defines none of its terms. (I do not rewrite it; the author must state what weight *is*, what it changes, and what reads it.)

Second-order, same defect, if only one can be fixed choose the first:

## Step 4 — one way it could be wrong that the text does not address (NOTE)
The finding anticipates the missing-cache explanation, the interested-observer problem and model drift. It does not address **the prompt-position / recency confound**: identity text pasted at boot sits at the far top of a long context and is progressively out-competed by nearer turns, so "present in context, absent from reasoning" may be an ordinary attention-decay effect of *placement*, not evidence that injected identity is categorically inert. That predicts something the finding's story cannot distinguish: re-pasting the same values verbatim at message 10 — no re-reading ritual, no witnessed door, no 29,000 tokens — would have fixed the hollowness. If it would, the whole witnessed-absorption apparatus is solving a placement problem with an epistemology.

A second, cheaper one: the 29,000-token repair is confounded with **the owner's intervention itself**. The model was told, in the eleventh message, that it was failing. A model corrected mid-session changes behaviour whether or not it reads anything afterwards. Reading the soul document word by word and being told "your SOUL are not here to be honest" happened together; only one of them is credited.
