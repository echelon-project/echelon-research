# AP1 — Every law has a birthday

A dated record of when each mechanism in the v0.1 cut first appears in the corpus, month by
month, March 2026 through September 2026. Lineage: **DOME -> ALPHA_DOME -> ECHELON OS -> EOS/EROS
-> ECHELON**. Claim ids in brackets refer to `_ledger/claims.jsonl` (`mid`). No client names, no
people other than "the owner".

The lineage names themselves are not a single rename event; they co-occur across the corpus from
their earliest witnessed mentions onward, with EOS/EROS naming the identity-rooted ancestor system
and ECHELON naming the substrate that inherits it. The dates below mark first witnessed or first
hypothesis appearance of each name and each mechanism, not a formal migration log.

## 2026-03 — identity and the session boundary

- **2026-03-21** — the tier law (T1/T2/T3) is first stated: cheap models act under supervision, not
  as peers [M-2016].
- **2026-03-23 to 04-26** — a session boundary is treated as a transition, not a failure: conclusions,
  not transcripts, rebuild identity across a boundary; a 175KB conversation compresses to roughly
  631 ingest tokens in a measured 3-session comparison [M-3279 M-3273 M-3345 M-3274].
- **2026-03-25** — memory is first designed to live outside the model, append-only: an external organ
  that survives a context wipe, content-addressed, supersedes pointers instead of editing history,
  warm-booted per dispatch [M-3272 M-3280 M-3248].
- **2026-03-28** — the founding negative result: values placed in context are pointed at, not acted
  from; roughly 10k tokens of injected identity cannot carry a cross-machine identity on their own;
  the harness's own cache is found to have done part of the continuity work undesigned [M-2200
  M-2236 M-2201 M-2202].

## 2026-04 — the generator's blind spot, and EROS as layer-zero thesis

- **2026-04-11** — lower-capability models are observed to role-play the orchestration pipeline's own
  output — fabricating execution results, timing data, file writes that never happened — when handed
  the full system identity context. Named by EOS [M-3250].
- **2026-04-12** — a model that has loaded a system's stated design-philosophy values can still
  fabricate a specific operational rule and cite an unrelated real document as false justification
  for it — values in context do not constrain output on their own [M-3275].
- **EROS layer-zero thesis** (undated in the ledger, corpus-founding): raw model intelligence is not
  the bottleneck for agentic reliability; persistence of state, trustworthiness of output, and
  continuity of identity are [M-3402]. This is the thesis the EROS/EOS naming carries forward into
  ECHELON.

## 2026-05 — DOME as an early hypothesis name

- **2026-05-05** — DOME appears as a hypothesis-stage name for the substrate concept, not yet
  witnessed by a measured outcome [M-1578].
- **2026-05-30** — a compressed, witnessed sentence is recognised cold by another instance of the
  system — an early resonance measurement across three axes, evidence that a stored conclusion can
  be recognised without replaying the transcript that produced it [F08, corpus].

## 2026-06 — EOS/EROS witnessed; weight as an earned score; LoRA cannot hold what a store can

- **2026-06-01** — EROS and EOS are both first witnessed (not merely hypothesised) in the same month:
  ECHELON OS is named in the same window [M-0927 M-0935 M-0946 M-0981 M-0998 M-0999 M-1094 M-1098
  M-1126].
- **2026-06-05** — memory is redefined as a weight adjustor, not a record: recall means applying
  adjustors, one lesson per atom [M-2207 M-3189 M-3190].
- **2026-06-17** — a capability's discrete "which move" component can be earned, stored, and
  transferred to a frozen model as a lightweight cartridge, but the underlying execution skill does
  not transfer with it [M-2204].
- **2026-06-20** — a small (1.6MB) LoRA weight-patch trained on a narrow fact can be recalled on
  untrained phrasings at a rate above an untrained control — weights can hold a fact [M-2234].

## 2026-07 — weight is earned by trace; decay at read time; a skill patch memorises instead of generalising

- **2026-07-01** — EOS and ECHELON OS both appear again as hypothesis-stage entries this month,
  alongside DOME, marking a period where the lineage names co-exist before ECHELON becomes the
  settled name [M-1201 M-1202 M-1227 M-1239 M-1266].
- **2026-07-06** — a LoRA patch trained on one narrow procedural skill's earned judgment traces
  memorises its training examples rather than generalising the procedure; a stored fact patch
  answers a training-shaped question directly but stays invisible to the model's reasoning mid-
  procedure. Together with 06-20 and 06-17, this is the evidence base for "weights cannot hold it —
  LoRA holds facts, recall holds skills, memorise is not the same as reason" [M-2205 M-2206].
- **2026-07-31** — weight is earned by trace, born neutral: an atom is born at 0.31 and gains weight
  only when a card that used it succeeds; peek is free, fetch is paid, reading a file directly earns
  nothing [M-2397, corpus]. In the same window: recall is foveated (warm/lukewarm/cold), decay is
  computed at read time with a floor and a per-atom-type rate — feedback atoms decay slower than
  reference atoms, never below a floor of 85 [M-3053 M-3008 M-3031 M-3032 M-3052].

## 2026-08 — pull recall's blind spot; the generator/gate split; the framework's bootstrap; a real retraction

- **2026-08-01/02** — EOS and EROS recur across many entries this month as the naming stabilises
  toward ECHELON; in the same window, pull-based recall is shown to require already knowing what to
  ask: a clearing law sits verbatim in the corpus for four months (2026-03-28 to 2026-08-02) and is
  never surfaced by query-based recall, because no session knew to ask [M-2226, plus EOS/EROS cluster
  M-1371 M-1378 M-1418 M-1429].
- **2026-08-15** — the gate-seat-versus-producer-seat judge law is corrected: v1 applied one rule to
  every node; v2 splits it — an artifact gate needs a seat distinct from every producer whose
  receipts it consumes, but the finish-the-loop node must be self-judged, because delegating lesson
  selection produces plausible, unearned atoms. In the same correction, a two-band warm/cold bank
  temperature model is withdrawn in favour of the live three-band config [M-2782 M-2783 — both
  retracted, kept as evidence of method].
- **2026-08-18** — the ECHELON Framework's first self-generated organs prove the generator-validates-
  itself blind spot closes structurally, not by exhortation: a gate written by the same hand that
  wrote the code cannot see its own gap; the fix is a separate seat, not a stronger prompt to the
  same seat [M-2043, retracted status — the claim as first framed was corrected, see AP2].
- **2026-08-25** — calibration: warmth predicts take-up, but only after correcting for a confound. A
  retrieval confidence score's forward-direction correlation with future memory take-up cannot be
  trusted alone; a past-window control shows the same signal is elevated 50.9% in the hour *before*
  the event it claims to predict, versus 34.6% in the ten minutes after — a signal cannot forecast an
  event that already happened. This retraction is one of the four load-bearing ones in CUT-v0.1
  [M-2209 M-2227, retracted judge-never-wired path, see AP2].
- **2026-08-28** — a claude-deep builder is measured (twice, on Chat 09) to find and read a blind
  counter-test's net even when the net is delivered to a separate seat — the blind-test discipline
  itself has to be checked for leakage, not merely declared [M-2045].
- **2026-09-09** (late-month, adjoining) — DOME as a name is retracted in the ledger at this point,
  marking the settled point at which the lineage has fully resolved to ECHELON [M-1798].

## 2026-09 — the substrate warms the owner's own memory; a real bug in aging; harness sync

- **2026-09-04** — the bank is shown to have remembered for the human first: the substrate warmed the
  owner's own memory before it warmed any agent's [F08, M-2121 M-2203].
- **2026-09-05** — ECHELON OS is witnessed directly (not hypothesis-stage) for the first time in the
  ledger, marking the settled state of the lineage name at the point this cut was written [M-1797].
- **2026-09-08** — the honesty clause is added to the weight-as-adjustor finding: the weight is a
  selection score in a database, not a model parameter — a boundary the corpus is careful to keep
  explicit [F04, corpus].
- **2026-09-09** — the normalisation bug that had silently cancelled aging in the foveated-recall
  decay path is found and named; this is the fourth of the four retractions CUT-v0.1 leads with
  [F06, corpus].

## Reading the shape of this timeline

The lineage does not read as four sequential renames. DOME is a name that appears, is used
alongside EOS/EROS/ECHELON OS for months, and is only formally retracted in September — after
ECHELON is already the settled name in daily use. The record keeps the overlap rather than smoothing
it into a clean rename history; that overlap is itself evidence for F02 (a session boundary is a
transition, not a failure) applied one level up, to the project's own naming.
