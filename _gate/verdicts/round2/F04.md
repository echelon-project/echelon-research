# F04 — A memory is a weight-adjustor, not a record — round 2, zero-context skeptic

**Verdict: PASS.**

### 1. Claim, stated back
On 2026-06-05 the owner replaced the ordinary store-and-retrieve model of memory with a frame — a
stored memory is an adjustor that re-shapes a model when the model chooses to read it — and that
frame produced four decisions that are in the code today: one lesson per file, content-hash
identity, a closed directed edge vocabulary of modulations, and a free peek against a metered fetch.
The behavioural half of the frame (that reading re-shapes rather than merely informs) is stated
here as an unrun hypothesis, not a result.

Claim stated, and the file draws the line itself: "That much is the finding." What is asserted is
*frame adopted + four decisions shipped*. The stronger psychological claim is explicitly demoted to
a hypothesis with a named falsifier and an admission that neither arm was run. Judged on the
claim made. Pass step 1.

### 2. Evidence line
The evidence for the claim actually made is witnessed and is not intent:
- the correction is a dated verbatim quote from a live design session — *"we cannot use a normal
  memories logic. because the memories are weight adjustor, transformer in a database"* — which is
  evidence of the *adoption event*, and adoption is what is being claimed;
- the four consequences are checkable in the artifact rather than asserted: one lesson per file
  "enforced by the ingest path, not by convention"; the edge vocabulary is enumerated in full
  (refines, supersedes, instances, part_of, depends_on, contradicts, refs, subsumes) so a reader can
  go and look; "No activation encoding was ever built" is a negative fact about the code.

Pass step 2, and the reason is that the finding refuses to launder provenance into proof. It says
outright: "The evidence is witnessed, not measured... a frame that produced engineering, not a
measured result." It then kills its own strongest-looking corroboration — the quote surviving in two
places — with "Two copies of an instruction are one instruction," and voids the corpus's own
evidentiary-basis label under the 2026-09-08 rule. A finding that pre-emptively disqualifies its own
second witness is not asserting.

If the file had claimed that adjustor-shaped recall *outperforms* record-shaped recall, this step
would fail — there is no held-out task, no before/after number on the atom split. It does not
claim that.

### 3. Mechanism rebuilt in five lines, from the text alone

```
write(lesson):   one lesson per file; fused file rejected at ingest
plant(atom):     id = sha(content); insert-or-ignore; score = NEUTRAL (author cannot set it)
link(a,b,rel):   rel in {refines,supersedes,instances,part_of,depends_on,contradicts,refs,subsumes}
peek(intent):    recall --warm -> spine previews only; free; writes nothing
apply(atom):     remember -> full body; records take-up; this is the only earning door
```

Reproducible. The pieces a stranger needs are all present: hash-as-identity gives idempotence,
insert-or-ignore gives the replant semantics, the edge vocabulary is closed and listed, born-neutral
is defined here and cross-referenced to F05, and the scope rule for ingest is glossed in place
("the named partition of the bank the lesson belongs to") including the mismatch-without-override
refusal. Pass step 3.

Named gap, non-fatal: what `recall --warm` scores *with* is not given — "scores candidates against
the current intent" is a black box, and warmth's formula is neither here nor in AP3. An implementer
can build the store, the edges, and the two doors from this text, but must invent the scorer. Since
the claim is about the frame and the four decisions, and the four decisions are all reproducible,
this does not fail the step — but it is the single largest hole for anyone rebuilding.

### 4. NOTE — one way it could be wrong that the text does not address
The text is already brutal on itself: it kills the "weight" metaphor with its own source audit
("does not modify an LLM's parameter tensors"), concedes one-lesson-per-file has an independent
justification that needs no adjustor frame at all, names the two-surfaces scoring inconsistency, and
lays out the take-up circularity — including the sharp version, that an atom which never surfaced is
indistinguishable in the store from one that surfaced and was rejected, so the reuse offered as
evidence is "partly manufactured by the ranking the frame installed." That last paragraph is more
damaging than anything an outside skeptic would have volunteered.

What it does not address: **the four decisions are over-attributed to the frame.** The finding's
own defence of the frame ("a productive metaphor that produced correct engineering for reasons
other than the ones it gives") is applied to decision one and not to the other three, yet each has a
mundane parent that predates any theory of memory — content-hash identity is standard
content-addressable storage, a closed typed edge vocabulary is ordinary schema discipline against
free-tagging, and free-list-versus-paid-fetch is a common cost-control split in any retrieval system.
If all four would have been arrived at by a competent engineer with no adjustor frame, then the
witnessed thing reduces to "an owner said a sentence and the team did sensible things afterwards,"
and the claim's second half — *that it produced them* — has no counterfactual behind it. Nothing in
the record shows a design decision the frame produced that ordinary engineering would not.

Second, smaller: "everything that touched weight, we will adapt" is quoted as scope, but no audit of
what *was* adapted versus what was already that way is offered, so the frame's blast radius is
asserted at exactly the point where it could have been counted.

### 5. Terms used before defined
No fatal case, and the inline glossing here is the best of the three files I read. *atom* is defined
at first use ("one lesson per file (an *atom*)"), *scope* is glossed inside the Mechanism sentence
that needs it, *take-up* is glossed at first use ("whether an atom that surfaced was actually pulled
through and acted on rather than merely listed"), *born neutral* is defined and cross-referenced.
`spine` appears in the Mechanism ("spine previews") undefined locally but present in AP3.
"Gate banner" (Where it came from) is used undefined and is not in AP3 — a stranger meets it as
"the thing prepended to every project's memory index," which is enough to keep reading but is the
one term here doing unearned work. Minor.
